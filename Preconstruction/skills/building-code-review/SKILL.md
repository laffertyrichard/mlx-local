# Jurisdiction-specific building code research

Establish the applicable authority and code basis before a binding project conclusion. The newest model code is not local law; a correct code quote alone does not establish project applicability or field compliance.

## Resolve authority and date

Ask for the minimum facts that change the decision: address/APN, actual building/use and proposed scope, permit/application/approval dates and status, and relevant existing/proposed evidence. Verify parcel boundaries/jurisdiction using official records; postal city, nearby fire station and county location are insufficient. Establish building, zoning and fire authorities separately. Continue general education or conditional review while these facts remain unresolved.

Read [jurisdiction workflow](references/jurisdiction-workflow.md). Browse live official sources for actual project reviews, inspect the relevant document bodies and retain conflicts. Trace departmental index → enacted adoption/incorporated edition → local amendments/selected appendices/referenced standards → effective dates/permit transition. Label policies, interpretations, checklists, proposals and adopted text distinctly. Recheck at project review and before submission. Use the [Arizona starter register](references/arizona-starter-register.md) only as dated research leads, never cached current authority.

## Establish applicability

Determine locally adopted IRC versus IBC scope and existing-building path from actual use, arrangement, stories and adopted definitions. “Condo” or “residential” marketing does not settle it. Confirm IEBC adoption/incorporation and permitted compliance method; work-area levels are method-specific. Neither blanket grandfathering nor universal whole-building upgrade follows from a remodel.

Review relevant parallel streams: zoning/overlays, fire/egress, structure, plumbing/fuel gas, mechanical, electrical, energy/green and accessibility. Keep HOA/landlord/title restrictions separate. Distinguish legal accessibility obligations from user design goals and federal requirements from municipal approval. Do not cherry-pick editions, IEBC methods or IPC/UPC provisions.

## Record and issue findings

Read [evidence matrix](references/evidence-matrix.md) for the concise project/source/finding fields and resolution states. Every binding conclusion needs **edition + exact section/table/exception + local adoption/amendment + applicability reasoning + supplied project evidence + retrieval date**. If any necessary link is missing, state the narrow gap. Separate approved drawings, proposed revision and observed field condition; approvals do not prove installation or concealed capacity.

Use authorized accessible publisher text; see [sources and access limits](references/sources.md). Do not invent inaccessible sections, quote proposals as law, collect pirated manuals or claim unseen paid content.

Deliver a decision summary, relevant evidence matrix, prioritized gaps and actionable questions for the responsible professional, field verifier or AHJ. Stop only the dependent conclusion. Prepare questions without sending, submitting, paying or uploading unless authorized. Route design alternatives to interior-design/architectural-planning and quantity mechanics to plan-area-takeoff when available. No concept, checklist, rendering, model readback or document-only finding establishes engineering safety, compliance certification or permit approval.
