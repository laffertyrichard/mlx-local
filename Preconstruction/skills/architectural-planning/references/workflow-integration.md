# Maturity and model/estimate handoff

## Issue at the intended stage

| Stage | Useful result and limit |
|---|---|
| Brief/feasibility | Activities, priorities, evidence and constraints; unknowns do not prove feasibility. |
| Concept/schematic | Distinct options, approximate source-labeled dimensions, essential views, intervention/cost drivers; subject to verification. |
| Design development | Selected option, reconciled dimensions, products/assemblies, structural/MEP interfaces and updated cost basis; open coordination remains visible. |
| Construction-document support | Qualified project team, field verification, coordinated details/calculations, applicable code documentation and required responsibility/signoff. A detailed model is not a substitute. |

AIA phase guidance [S2–S4 in sources.md](sources.md) informs these distinctions; actual deliverables depend on the user's agreement/scope, not a phase label alone.
