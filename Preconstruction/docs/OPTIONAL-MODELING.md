# Optional drawing/model fidelity boundary

The inspected Blender architecture skill is project-bound and contains private decisions; it is not bundled. The local takeoff MVP neither requires Blender nor contacts Prime.

Transferable guidance from that source: establish authority by the decision, retain competing revisions and units/datums, distinguish room membership from quantity ownership, preserve an approved shell, register physical owners independently of floor deductions, and compare orthographic plans/elevations against originals. Inspect operations, aperture junctions and hidden/partial scope rather than relying on beauty views or total volumes. An outline evidence envelope with unknown host/thickness is not a measured finish mask. Use stable physical IDs and explicit unknowns. A saved-file readback proves persistence, not source fidelity or code/field approval.

If a later task explicitly authorizes modeling, re-read that checkout's instructions and current skill files. Configure `OPTIONAL_BLENDER_WORKSPACE` explicitly, verify runtime readiness, preserve unrelated live scenes, use isolated candidates and one live writer, then separately inspect the saved artifact. A historical path or prior approval is not permanent execution authority. Fabrication/IFC/native-scene delivery is outside this package's acceptance scope.
