Requirements

  • Apple silicon Mac running macOS 14 or newer
  • uv and the MLX tools needed for the modalities your team uses
  • Enough local disk and unified memory for the selected model

Before using every backend, install:

uv tool install mlx-lm
uv tool install mlx-vlm
uv tool install 'mlx-audio[server]'

Open MLX Menu from Applications after installation. Model downloads are always explicit. Inference workers bind only to 127.0.0.1.

The package does not add a login item. Add MLX Menu in System Settings → General → Login Items if desired.
