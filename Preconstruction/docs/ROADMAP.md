## First deliverable for Claude

Implement phases 0–2 as the first coherent vertical slice: create/select a project, import a synthetic PDF, calibrate and review a room with a fixed deduction, calculate deterministic quantities, save/reopen and show a draft scope preview based on a deterministic template. The scope preview is explicitly not phase-4 model generation. Keep new APIs testable with mock runtimes. Retain Manual/V1 and Auto routing behavior.

Proceed beyond that slice only under the subsequent development task's scope. A useful manual takeoff is a safer prerequisite to assisted interpretation than treating the current tracer as a plan interpreter.

## Evaluation strategy and limits

Use package tests now as helper/contract evidence. During development, add Swift Testing for domain/calculation/state and RouterEvaluation fake runtimes for routing/permissions/resume. Add raster/source-fidelity fixtures with known ground truth; keep training/development fixtures separate from held-out evaluation. Freeze source/profile/validator versions. Report source extraction, interpretation, topology, arithmetic, scope completeness and artifact fidelity separately. Request an appropriate quiet execution window before actual model evaluations on the shared pricing Mac. Never use customer files as automatic fixtures.
