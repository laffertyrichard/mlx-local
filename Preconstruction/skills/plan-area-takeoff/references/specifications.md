# Specifications and revisions

Inventory the actual files, dates and received pages before cross-referencing. Compare printed “page X of Y” and sheet indexes with received content; a filename alone does not prove a complete set. Read scans visually/OCR as needed; text extraction alone can miss entire pages. Identify referenced but absent appliance quotes, schedules and details without inventing their contents.

Map each measured finish tag to product, manufacturer/supplier as stated, size, thickness, pattern/direction, grout/trim, edge treatment, replacement scope and source page. Preserve uncertain names/source spellings rather than silently substituting a plausible product. A tag alone is not a material category: a wall finish might be limestone veneer or decorative plaster, not wallpaper. Room-level product assignments can remain provisional for a separately labeled “TBD” surface.

Use the required callout and question fields in [design-coordination.md](design-coordination.md). Keep a review register with stable issue ID, affected rooms/quantity IDs, drawing and spec references, discrepancy, selected treatment and quantity effect. Respect explicit document precedence when provided; otherwise state the adopted basis instead of assuming every later-looking file governs. Explicitly selected provisional specification dimensions are allowed, but cannot be presented as measured drawing geometry.

When updating an existing takeoff:

Use the revision-deltas procedure routed from SKILL.md to preserve the prior snapshot and report quantity, material, scope and measurement-basis changes. Use the material-ordering procedure when selections establish product/package information and order quantities are requested.

1. Preserve quantity IDs, source calibration and doorway allocations unless a correction is justified and its effect recorded.
2. Apply resolved products and scope changes throughout detailed rows, summaries, notes and overlays. Remove superseded “specification pending” or “material TBD” statements only where actually resolved.
3. Retain excluded existing measurements as clearly labeled reference quantities, separate from new-work totals. Keep repair quantities unknown when not established.
4. Keep unresolved dimensional alternatives outside the selected total. Do not add the old and revised quantity together.
5. Recheck linked surfaces: bench depth affects floor coverage; tile insets affect slab backsplash; separate mirror/slab faces affect wall fields.
6. Regenerate artifacts from the revised manifest and verify source-to-quantity agreement again. Record changes in the report, not only in commentary.

No project-specific product, dimension, finish-code meaning or installation assumption becomes a default for the next project. Do not embed client drawings or prior takeoff quantities in this reusable skill.
