# Flooring interpretation

For a request for all flooring, inventory every in-scope room and finish before tracing: tile, wood, stone hearths and any other specified flooring. Reconcile halls, closets, alcoves and room-to-room thresholds; do not stop after wet areas. Do not infer conditioned status or replacement scope solely from proximity to the house.

Choose and state a flooring installation basis before deduction. If the documents do not establish it, show gross and the assumption-sensitive deduction so the decision can be revised.

| Element | Treatment to investigate |
|---|---|
| Interior partitions | Exclude their solid footprint. Preserve the doorway opening. |
| Fixed base cabinets / closet islands | Deduct the supported base footprint only if flooring stops there. Counter outline may include overhang; use it only as a disclosed proxy if no better base evidence exists. |
| Kitchen island | Distinguish cabinet bases, seating overhang, end panels, and appliances. Dashed lines may indicate concealed bases or something else; check keynotes/details. |
| Removable appliances | Retain floor beneath unless the installation specification or raised platform establishes otherwise. An appliance drawn inside a counter outline may need an explicit addback. |
| Washer/dryer platform | Deduct confirmed raised construction separately from appliance symbols. Flag inferred envelope dimensions. |
| Open rods / shelves / upper cabinets | Usually do not consume floor area. Distinguish floor-supported casework from overhead or open shelving. |
| Floating slab vanity | Retain flooring beneath unless the construction detail establishes a floor-supported enclosure. Measure its slab top/apron independently. |
| Makeup vanity / knee space | Floor below open knee space may remain; make any whole-footprint deduction explicit and reviewable. |
| Toilets | Do not deduct the fixture symbol footprint from a normally continuous tiled floor. |
| Shower | Remove enclosure/curb footprint from general bath flooring. Measure interior shower floor separately; curb, wall tile and waterproofing are other quantities. |
| Stairs | Do not count a projected stair footprint as ordinary planar flooring. Landings can be included if clearly bounded; tread/riser takeoff requires a separate method. |
| Flush hearths | Deduct the hearth footprint from surrounding wood and schedule the hearth material separately once. A raised or retained hearth needs its own scope classification. |
| Furniture | Retain flooring; furniture outlines are not construction boundaries. |
| Door thresholds | Allocate to one zone, noting finish transitions. Avoid gaps or duplicates between zones. |
| Garages, patios, existing rooms | Include only within the requested scope and applicable finish, regardless of their appearance on the same sheet. |

Keep finish assignment separate from area confidence and replacement scope. Do not carry material-letter conventions, building area totals, casework assumptions or a selected west/east boundary from one project into another.
